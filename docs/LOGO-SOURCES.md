# Institution logo sources

Downloaded on 2026-09-25. Marks retain their original colors and proportions and identify the institutions listed in the author's experience and education.

- **NVIDIA:** [official logo and brand page](https://www.nvidia.com/en-us/about-nvidia/legal-info/logo-brand-usage/), [vertical SVG](https://www.nvidia.com/content/nvidiaGDC/us/en_US/about-nvidia/legal-info/logo-brand-usage/_jcr_content/root/responsivegrid/nv_container_392921705/nv_container/nv_image.coreimg.svg/1776076920288/nvidia-logo-vert.svg). Saved as `assets/img/logos/nvidia.svg`.
- **Zhejiang University:** [official university emblem page](https://www.zju.edu.cn/514/listm.htm), [PNG asset](https://www.zju.edu.cn/_upload/article/images/c3/98/1fb1d281492eb477a098ef7a2901/6d8d432f-56ac-47eb-b22d-a23b103aed01.png). Saved as `assets/img/logos/zju.png`.
- **National University of Singapore:** [public logo archive](https://logotyp.us/logo/nus/), [SVG asset](https://logotyp.us/file/nus.svg); visual reference: [NUS identity](https://www.nus.edu.sg/identity/). Saved as `assets/img/logos/nus.svg`. The official main site's image downloads returned a security page, so the standard full university mark was obtained from this archive.

SVG view boxes were tightened to remove excess outer whitespace; paths, colors, and aspect ratios were not changed. The logos belong to their respective institutions and are not covered by the site's code license.
